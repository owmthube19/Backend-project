A backend project built using Node.js, Express.js, MongoDB, and Mongoose.

The project implements core backend functionalities of a video-sharing platform, including user authentication, video management, comments, channel subscriptions, and watch history.

Tech Stack:-
1. Runtime: Node.js
2. Framework: Express.js
3. Database: MongoDB, Mongoose
4. Authentication: JWT, bcrypt
5. Media Management: Cloudinary, Multer

Key Features:-
1. User registration, login, and token-based authentication
2. Video upload and management
3. Comment and subscription management
4. User channel profiles and watch history
5. RESTful API development and MongoDB aggregation pipelines
